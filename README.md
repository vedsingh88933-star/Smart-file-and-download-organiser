# Smart File Organizer CLI

A light, fast, and automated Command-Line Tool built in Python to organize cluttered directories into categorized subfolders based on file extensions.

---

## 📌 Project Overview

The **Smart File Organizer CLI** scans a designated target directory (e.g., `Downloads`, `Desktop`, or custom paths) and moves files into organized subdirectories. It runs purely from the command-line interface (CLI), requiring zero GUI dependencies.

---

## 🛠️ Prerequisites & Environment Setup

- **Python Version**: Python 3.8 or higher.
- **Dependencies**: Built entirely using standard Python library modules (`os`, `shutil`, `pathlib`, `argparse`, `logging`). No external package installations (`pip install`) are needed.
